fPaint

Free, open-source raster graphics editor

Professional drawing and painting tools, completely free: no ads, no paywalls, no premium tiers. Built with Flutter, fPaint runs from one codebase on iOS, Android, macOS, Windows, Linux and the web.

Open fPaint in your browser macOS Windows Linux Source on GitHub

Features

  • Brushes & effectsPressure-sensitive brushes, smudge, blur and effects you paint on like any other brush.
  • LayersA full layer system with blend modes, opacity, locking and reordering.
  • SelectionsRectangle, ellipse, lasso, magic wand and a selection brush, with add and remove.
  • ColorColor wheel, palettes, recent colors, solid and gradient fills.
  • Quick menuA radial menu at your cursor or pen with your recent tools, colors and brush size.
  • File formatsPNG, JPEG, TIFF, WEBP, HEIC, OpenRaster (ORA), and Photoshop (PSD) import.
  • Touch, pen and mouseControls sized for the input you use, with keyboard shortcuts on desktop.
  • Undo & redoA full history so you can experiment freely.
